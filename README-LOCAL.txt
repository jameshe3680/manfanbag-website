满帆英文官网 · 完整本地版

包含：首页、Collections、About Us、Service、Insights、Contact Us、Start a Project。

1. 完整解压压缩包，双击根目录 index.html 打开首页。
2. 从顶部导航、页脚或首页卡片访问子页面。
3. 不要改变 HTML、图片、CSS 和 JS 的相对位置。

本地服务器（可选，需要 Python 3）：
在此文件夹打开终端，运行：
python3 -m http.server 8080 --bind 127.0.0.1
Windows 可运行：py -m http.server 8080 --bind 127.0.0.1
浏览器访问 http://localhost:8080 ，终端按 Ctrl+C 结束。

询盘表单：
Contact Us 和 Start a Project 填写后点击 Prepare Email Draft。
检查草稿，点击 Open Email App 打开邮件应用，由用户确认发送。
如果未配置邮件应用，点击 Copy Draft 复制，粘贴至邮箱并发往 info@mffind.com。
本地文件模式下若浏览器不允许自动复制，会选中草稿；按 Command+C 或 Ctrl+C 即可。
附件请在邮件应用中添加。网页不会自行发送、上传或存储表单内容。

网站页面、图片、样式和脚本可离线使用；邮件发送和 LinkedIn 需要联网。
